## 📌 About the Bootcamp
The **n11 TalentHub Backend Bootcamp** is an intensive program focused on building scalable, maintainable, and high-performance backend systems. The curriculum covers a wide range of modern technologies and industry best practices, including:

- **Java & Advanced Programming Techniques**
- **Spring Boot & Microservices Architecture**
- **SOLID Principles & Design Patterns**
- **Database Management & Hibernate/JPA**
- **RESTful API Development**
- **Testing & Clean Code Standards**
